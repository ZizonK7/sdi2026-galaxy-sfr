# study/

대회 준비 공부 자료 (최소한 ver, 2026-10-28). 원본은 사용자의 학습 저장소(Professor_King)의 "대회 공방 (은하 별 생성률 예측)" 과목이고, 여기는 사본이다.

- AI 튜터(채팅 AI)에게 수업정리 파일 하나를 통째로 주고 "이 문서대로 수업해 줘"라고 하면 블록 단위로 가르쳐 준다.
- 순서: `1-1` 은하와 데이터 → `1-2` 그래디언트 부스팅 → `2-1` 타깃 처리(핵심) → `2-2` 해석과 중간 보고서.
- `선수지식_지도.md`: 필요한 개념이 어느 수업에서 이미 나왔는지. 수업 경로는 Professor_King 기준이라 이 저장소에는 없다.
- 각 수업정리의 "보고서에 옮기기" 절은 템플릿 어느 절에 무엇을 쓰면 되는지 안내한다. 문장은 직접 쓴다.
