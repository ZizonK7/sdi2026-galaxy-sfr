## 1. 수업 개요
- **수업 전체 한 문장 직관**: 모델은 손실 함수가 가리키는 양을 맞히므로, 손실이 지표와 다른 양을 가리키면 지표에서 진다.
- **한 줄 요약**: 같은 HGB로 (a) 제곱 손실 (b) log1p 변환 후 되돌림 (c) Poisson 손실 (d) 2단계 P×E를 돌려 `evaluate_sfr` 표로 비교하면 (a)와 (d)가 비슷하게 좋고 (b)는 0·MAE에서 좋지만 꼬리에서 지고 (c)는 RMSE에서 가장 나쁘다.
  이것을 "제곱 손실 → E[Y|X]", "로그 평균 → 중앙값 쪽(Jensen)", "Poisson → 상대 오차 가중(1/μ)", "P×E = E[Y|X]의 분해"로 유도해 설명하고, 7절 모델을 정한다.
- **수업 흐름**: 1단계(세 손실이 맞히려는 것 → 2단계 모델 아이디어 → 비교표 읽는 법·가설) → 실습(세 손실 표 → 되돌림 편향·보정·Poisson 트리 수 → 2단계 모델·`FINAL_MODEL`) → 2단계(P×E 유도 → Poisson deviance vs RMSE → Jensen과 보정).
- **선수 지식(연결)**: 심수기 7-2·2-1·2-2·3-1, 자분실 5·7·9, 확개응 8-1·8-2.
- **다음 회차 연결**: 2-2에서 이 회차의 모델 차이에 쌍 부트스트랩 구간을 붙이고, permutation importance로 해석하고, 8절을 쓴다.

### 2.3 블록 상세

#### [1단계 1/3] 세 손실은 세 가지 다른 것을 맞히려 한다
- **한 문장 직관**: 제곱 손실은 평균을, 로그 뒤 제곱 손실은 중앙값 쪽을, Poisson 손실은 "상대 오차로 재는 평균"을 맞히려 한다.
- **블록 목표**: (1) 세 선택지의 코드 한 줄과 "맞히려는 양"을 짝지을 수 있다. (2) 지표(선형 RMSE)가 셋 중 어느 양을 재는지 말할 수 있다.
- **설명할 내용**
  - [필수] **(a) 제곱 손실 그대로** — `HistGradientBoostingRegressor(loss="squared_error")`(기준선). 이미 배움 → 심수기 7-2 `[2단계 1/10]` 제곱 손실에서 target의 정체 (`심층신경망의 수학적 기초/7-2_수업정리.md`): 제곱 손실의 최적 예측은 η(x) = E[Y|X = x]. **이 대회에서는**: 지표가 선형 RMSE이므로 **맞혀야 할 양이 바로 E[SFR|피처]**다. (a)는 지표와 **같은 양**을 겨냥한다. 약점: 꼬리를 못 맞히는 건 손실 탓이 아니라 피처·외삽 불가·표본 270개 탓(1-2). 음수 예측 가능.
  - [필수] **(b) log1p 변환 후 되돌림** — `fit(X, np.log1p(y))` → `np.expm1(pred)`. 로그 척도에서 제곱 손실 → **E[log(1+Y)|X]**를 맞힌다. 되돌리면 exp(E[log(1+Y)]) − 1 — 이것은 **E[Y|X]가 아니다**(Jensen: 작다, 2단계 3/3). 로그정규라면 exp(E[log Y]) = **중앙값**. 즉 (b)는 조건부 **중앙값 쪽**을 내놓는 모델이다. 이미 배움 → 자분실 7 `[1단계 4/9]` 손실 함수가 답을 정한다(L1 → 중앙값, 이상치에 둔감). **이 대회에서는**: 중앙값은 꼬리에 끌려가지 않으므로 0·보통 은하에는 좋고 **꼬리를 체계적으로 과소예측**한다 → RMSE에서 손해.
  - [필수] **(c) Poisson 손실** — `HistGradientBoostingRegressor(loss="poisson")`. 이미 배움 → 자분실 7 `[1단계 9/9]` 포아송 GLM(log μ = 선형, Var = μ), 확개응 8-1 `[1단계 1/8]` Poisson pmf, 심수기 2-2 `[2단계 2/9]`(잡음 가정이 손실을 정한다). **이 대회에서는**: Y|X ~ Poisson(μ(x)), log μ(x) = 트리들의 합, 음의 로그우도(deviance) 최소화. 모델이 맞다면 μ(x) = E[Y|X] — 평균을 겨냥하고, 예측은 항상 양수, 0도 자연스럽게 다룬다(P(0) = e^{−μ}). SFR은 카운트가 아니지만 deviance는 y ≥ 0 실수에서 정의된다. **그러나** deviance는 오차를 **상대적으로**(≈ (y − μ)²/μ) 잰다 → 큰 은하의 절대 오차를 RMSE보다 덜 벌한다 → 지표와 다른 양을 최소화 → 질 수 있다(2단계 2/3).
  - [필수] **한 줄 표**:

    | 선택지 | 코드 | 맞히려는 양 | 지표(선형 RMSE)와 |
    |---|---|---|---|
    | (a) 제곱 | `loss="squared_error"` | E[Y\|X] | 같은 양 |
    | (b) log1p | `log1p` → `expm1` | exp(E[log(1+Y)\|X]) − 1 ≈ 중앙값 쪽 | 다른 양(작다) |
    | (c) Poisson | `loss="poisson"` | E[Y\|X] (상대 가중) | 같은 양, 다른 가중 |

#### [1단계 2/3] 2단계 모델 — "0인가"와 "0이 아니면 얼마인가"를 따로
- **한 문장 직관**: 꺼진 은하와 만드는 은하가 다른 과정이라면 "꺼졌을 확률"과 "안 꺼졌을 때의 SFR"을 따로 배우고 곱하는 것이 평균을 맞히는 길이다.
- **블록 목표**: (1) 2단계 모델의 예측식 ŷ = P̂(Y > 0|x)·Ê[Y|Y > 0, x]를 쓰고 ZIP의 E[Y] = (1−π)μ와 같은 식임을 안다. (2) "곱"이지 "P > 0.5로 자르기"가 아닌 이유를 직관으로 말한다(식은 2단계 1/3).
- **설명할 내용**
  - [필수] **근거**: 1-1에서 0의 94%가 밀도 ≥ 1.5(환경 꺼짐)에서 나왔다 — "0을 만드는 과정이 따로 있다". 이미 배움 → 자분실 7 `[1단계 9/9]`·`[2단계 8/9]` zero-inflated: 확률 π로 구조적 0, 1−π로 Poisson(μ) → **E[Y] = (1−π)μ**. **이 대회에서는**: π(x) = P(SFR = 0|x)를 **분류기**로, μ(x) = E[SFR|SFR > 0, x]를 **양수 은하만으로 학습한 회귀기**로 따로 배우고 **곱한다**. 이름: hurdle / two-stage 모델.
  - [필수] **두 조각**:
    - 분류기 `HistGradientBoostingClassifier` → `predict_proba(X)[:, 1]` = P̂(Y > 0|x). 이미 배움 → 심수기 3-1 `[2단계 1/10]`~`[2/10]` 로지스틱 회귀: 확률을 내고 log loss(cross-entropy)를 최소화. **이 대회에서는**: HGB 분류기도 같은 log loss를 트리의 합 F(x)에 대해 최소화하고 p = σ(F) — 로지스틱의 **비선형 일반화**. 확률이 **보정**되어 있는지(p = 0.3이라 한 은하들의 30%가 실제로 > 0인지) 표로 확인한다(실습 3/3).
    - 회귀기 `HistGradientBoostingRegressor` → `y_train > 0`인 행만으로 학습 → Ê[Y|Y > 0, x]. 0을 빼고 배우므로 **0이 양수 예측을 끌어내리는 일**(기준선이 0을 +1.2로, 작은 양수를 과대·큰 양수를 과소하던 것)이 없어진다.
  - [필수] **왜 곱인가 (직관)**: p = 0.6, e = 5인 은하는 "60% 확률로 5, 40%로 0" → 평균 3. 자르면(p > 0.5 → 5) 늘 5를 말하는 것이고 **평균에서 2 벗어난다**. RMSE는 평균을 요구한다(블록 1). 그러나 p가 0.05나 0.98처럼 **확실**하면 곱과 자르기가 거의 같다 — 이 데이터가 그렇다(실측: 검증의 94%가 p < 0.1 또는 p > 0.9) → 2단계 모델의 이득이 **작을 것**을 예고한다.
  - [필수] **(d)의 양수 쪽 손실**: 회귀기에 제곱(d) 또는 Poisson(d′)을 쓸 수 있다. 블록 1의 논리로 지표에는 (d)가 맞다.
  - [선택] 세 조각 모델(0 / 보통 / 꼬리 전용)이나 꼬리에 가중치를 주는 변형은 완벽 ver.

#### [실습 2/3] 되돌림 편향과 보정, Poisson에 트리를 더 주면
- **한 문장 직관**: 로그 모델의 체계적 과소예측은 상수 하나로 일부 고쳐지고, Poisson의 패배는 트리를 많이 주면 거의 사라진다 — 둘 다 "무엇을 최소화했나"의 결과다.
- **할 일**:
  ```python
  # 7절 재료 2: (b) 되돌림 보정 (Duan smearing) — 훈련 잔차의 exp 평균을 곱한다
  z_train = np.log1p(y_train)
  resid_log = z_train - m_b.predict(X_train)
  smear = np.mean(np.exp(resid_log))                       # Duan(1983) smearing 계수
  lognormal_factor = np.exp(resid_log.var() / 2)           # 잔차가 정규라면 exp(σ²/2)
  print(f"smearing 계수 {smear:.4f} | 로그 잔차 분산 {resid_log.var():.4f} → exp(σ²/2) = {lognormal_factor:.4f}")
  preds["(b') log1p + smearing"] = np.exp(m_b.predict(X_val)) * smear - 1
  # (c') Poisson에 트리를 더 주면 (학습률 낮춤·트리 수↑·잎↑) — 최적화가 덜 된 것인지 확인
  m_c2 = HistGradientBoostingRegressor(loss="poisson", learning_rate=0.05, max_iter=600, max_leaf_nodes=63, random_state=RANDOM_SEED).fit(X_train, y_train)
  preds["(c') poisson 600 trees"] = m_c2.predict(X_val)
  m_a2 = HistGradientBoostingRegressor(learning_rate=0.05, max_iter=600, max_leaf_nodes=63, random_state=RANDOM_SEED).fit(X_train, y_train)
  preds["(a') squared 600 trees"] = m_a2.predict(X_val)
  print("Poisson 600 n_iter_:", m_c2.n_iter_, "| squared 600 n_iter_:", m_a2.n_iter_)
  table2 = pd.concat([evaluate_sfr(y_val, preds[k], k) for k in ["(a) squared", "(b) log1p->expm1", "(b') log1p + smearing", "(c) poisson", "(c') poisson 600 trees", "(a') squared 600 trees"]], ignore_index=True)
  print(table2[table2["Regime"].isin(["All", "SFR = 0", "Top 10% SFR"])].round(3).to_string(index=False))
  print("보정 뒤 예측 평균:", round(preds["(b') log1p + smearing"].mean(), 3), "(참 3.751)")
  ```
- **받아야 할 출력** (Claude 실측): `smearing 계수 1.0326 | 로그 잔차 분산 0.0585 → exp(σ²/2) = 1.0297`. (b′) All **9.785**, 0 regime 1.004, Top 10% 30.799, 예측 평균 **3.489**(3.347 → 3.489, 여전히 3.751 미달). (c′) Poisson 600: All **9.550**, 0 regime 2.021, Top 10% 29.487 — (a)와 거의 같다. (a′) squared 600: 9.537. `n_iter_`: Poisson 600 → **136**, squared 600 → **61**(둘 다 상한 600 전에 멈춤; Poisson이 두 배 넘게 더 간다 — 곱셈 갱신이 꼬리까지 가는 데 걸음이 더 필요하다는 2단계 2/3의 모습).
- **디버깅 체크리스트**:
  1. (b′)에서 `np.exp(...) * smear - 1` — `expm1(pred) * smear`가 **아니다**(1을 더한 뒤 곱해야 한다: 1 + y = exp(z)). 틀리면 평균이 더 작게 나온다.
  2. 600개 학습이 느림(10~20초) → 기다린다. 더 느리면 `max_iter=300`.
- **확인 문제**

#### [실습 3/3] 2단계 모델 → `FINAL_MODEL`
- **한 문장 직관**: 분류기와 회귀기를 `fit`·`predict`가 있는 클래스 하나로 묶으면 템플릿의 `FINAL_MODEL` 자리에 그대로 들어간다.
- **할 일**: 7절 `# STUDENT TODO — replace this example with your model.` 칸의 내용을 아래로 **바꾼다**(이 칸은 바꿔도 된다). `FINAL_MODEL`·`FINAL_TRAIN_SECONDS`·`VAL_PREDICTIONS` 이름을 지킨다.
  ```python
  # 7절: 2단계(hurdle) 모델 — P(SFR>0 | x) × E[SFR | SFR>0, x]
  from sklearn.ensemble import HistGradientBoostingClassifier
  from sklearn.metrics import roc_auc_score, log_loss

  class TwoStageSFR:
      """분류기 P(y>0|x)와 양수 전용 회귀기 E[y|y>0,x]를 곱한다 (ZIP의 E[Y] = (1-π)μ와 같은 식)."""
      def __init__(self, hgb_params, reg_loss="squared_error", clip_zero=True):
          self.hgb_params = hgb_params; self.reg_loss = reg_loss; self.clip_zero = clip_zero
      def fit(self, X, y):
          y = np.asarray(y, dtype=float)
          self.clf_ = HistGradientBoostingClassifier(**self.hgb_params).fit(X, (y > 0).astype(int))
          pos = y > 0
          self.reg_ = HistGradientBoostingRegressor(loss=self.reg_loss, **self.hgb_params).fit(X[pos], y[pos])
          return self
      def predict_proba_positive(self, X):
          return self.clf_.predict_proba(X)[:, 1]
      def predict_positive_mean(self, X):
          e = self.reg_.predict(X)
          return np.clip(e, 0, None) if self.clip_zero else e      # E[y|y>0] ≥ 0이어야 한다
      def predict(self, X):
          return self.predict_proba_positive(X) * self.predict_positive_mean(X)

  FINAL_MODEL = TwoStageSFR(hgb_params=dict(learning_rate=0.08, max_iter=150, max_leaf_nodes=31, random_state=RANDOM_SEED))
  _t0 = time.time()
  FINAL_MODEL.fit(X_train, y_train)
  FINAL_TRAIN_SECONDS = time.time() - _t0
  VAL_PREDICTIONS = FINAL_MODEL.predict(X_val)
  assert len(VAL_PREDICTIONS) == len(y_val)
  assert np.isfinite(VAL_PREDICTIONS).all()
  print(f"Training time: {FINAL_TRAIN_SECONDS:.1f} s")

  # 진단: 곱 vs 자르기, 분류기 품질과 보정
  p1 = FINAL_MODEL.predict_proba_positive(X_val); e1 = FINAL_MODEL.predict_positive_mean(X_val)
  hard = np.where(p1 > 0.5, e1, 0.0)
  yv = y_val.to_numpy()
  diag = pd.concat([evaluate_sfr(y_val, baseline_pred, "(a) baseline"), evaluate_sfr(y_val, VAL_PREDICTIONS, "(d) P x E"), evaluate_sfr(y_val, hard, "(d-hard) 1[P>0.5] x E")], ignore_index=True)
  print(diag.round(3).to_string(index=False))
  print(f"분류기 AUC {roc_auc_score((yv > 0).astype(int), p1):.4f} | log loss {log_loss((yv > 0).astype(int), p1):.4f} | 0.1 < p < 0.9인 비율 {((p1 > 0.1) & (p1 < 0.9)).mean():.1%}")
  cal = pd.DataFrame({"p": p1, "pos": (yv > 0).astype(int)}).groupby(pd.cut(p1, [0, 0.1, 0.3, 0.5, 0.7, 0.9, 0.99, 1.0]), observed=True).agg(n=("pos", "size"), mean_p=("p", "mean"), frac_pos=("pos", "mean"))
  print(cal.round(3))
  ```
- **받아야 할 출력** (Claude 실측, 위 코드 그대로 — `clip_zero=True`): `Training time` 약 1.5초. (d) P×E: All **9.434** / 0 regime 약 2.9 / Top 10% 약 29.2, R² 0.398(자르지 않으면 9.443 / 2.913 / 29.177 — 차이는 음수 예측 몇 개). (d-hard): All 9.463 / 0 regime 3.742 / Top 10% 29.146. (a) 9.513. 분류기 AUC **0.9945**, log loss 0.0507, `0.1 < p < 0.9인 비율 6.0%`. 보정표: (0, 0.1] n 2256, mean_p 0.039, frac_pos 0.035 / (0.1, 0.3] 984, 0.177, 0.174 / (0.3, 0.5] 388, 0.392, 0.371 / (0.5, 0.7] 348, 0.602, 0.632 / (0.7, 0.9] 761, 0.825, 0.820 / (0.9, 0.99] 3399, 0.964, 0.973 / (0.99, 1] 33552, 0.999, 0.999 — **잘 보정됨**(mean_p ≈ frac_pos).
  (`clip_zero=True`라 회귀기의 음수 예측이 0으로 잘린다 — 9.443 → 9.434, 단조 개선. 뒤의 `DO NOT MODIFY` 최종 평가 셀과 `RESULTS` 셀(`type(FINAL_MODEL).__name__` = `TwoStageSFR`, `validation_rmse` 9.434)이 그대로 돈다 — Claude가 끝까지 실행해 확인.)

## 4. 2단계 설계 — 수학 (약 30분, 3블록)

### 4.1 목표
- E[Y|X] = P(Y > 0|X)·E[Y|Y > 0, X]를 유도하고, 임의의 예측 c의 조건부 위험이 Var + (c − pe)²임을 보여 **자르기의 손해를 식으로** 쓸 수 있다.
- Poisson deviance가 음의 로그우도임을 보이고, 1차 조건(평균 보존)과 2차 근사((y − μ)²/μ)로 **"상대 가중"이 RMSE와 어긋나는 이유**를 쓸 수 있다.
- Jensen으로 되돌림 편향의 방향을 증명하고, 로그정규 보정 e^{σ²/2}와 smearing 추정량을 유도·연결할 수 있다.

#### [2단계 1/3] 2단계 모델은 조건부 기댓값의 분해다
- **한 문장 직관**: 평균은 "0이 아닐 확률 × 0이 아닐 때의 평균"으로 쪼개지고, 제곱오차를 최소화하려면 그 둘을 곱한 값을 내놓아야 한다.
- **블록 목표**: (1) 분해식을 총기대 법칙으로 유도한다. (2) 조건부 위험 식에서 자르기의 손해를 계산한다. (3) 두 조각이 각각 어떤 손실을 최소화해야 분해가 성립하는지 말한다.
- **설명할 내용**
  - [필수] **이미 배움 →** 심수기 7-2 `[2단계 1/10]` (`심층신경망의 수학적 기초/7-2_수업정리.md`): R(f) = E[(f(X) − η(X))²] + E[(Y − η(X))²], η(x) = E[Y|X = x], 교차항은 tower property로 0. **이 대회에서는**: 증명을 다시 하지 않고 결과만 쓴다 — 지표가 RMSE이므로 **목표 함수는 η(x) = E[SFR|x]**이고, 어떤 모델이든 η에서 벗어난 만큼 (f − η)²의 벌점을 받는다.
  - [필수] **분해 (유도)**: x를 고정하고 p := P(Y > 0|x), e := E[Y|Y > 0, x]. Y = Y·1[Y > 0] (Y ≥ 0이므로 Y = 0일 때 양변 0). 총기대 법칙(이미 배움 → 자분실 5 `[2단계 4/9]` 집계의 수학, 심수기 7-2의 tower property):
    E[Y|x] = E[Y|Y > 0, x]·P(Y > 0|x) + E[Y|Y = 0, x]·P(Y = 0|x) = e·p + 0·(1 − p) = **p·e**. ∎
    → 자분실 7의 ZIP E[Y] = (1−π)μ가 x마다 성립하는 꼴. 따라서 **분류기가 p를, 양수 회귀기가 e를 맞히면 그 곱이 η(x)**다.
  - [필수] **조건부 위험 (유도)**: x에서 상수 c를 예측할 때 E[(Y − c)²|x] = E[(Y − η)²|x] + (η − c)² (교차항 2E[(Y − η)(η − c)|x] = 2(η − c)·E[Y − η|x] = 0). 첫 항은 c와 무관한 **조건부 분산**, 둘째가 **초과 위험 (c − pe)²**. 최소는 c = pe.
    - **자르기**: c_hard = e·1[p > 0.5]. p > 0.5면 초과 = (e − pe)² = **(1 − p)²e²**; p ≤ 0.5면 **p²e²**. 예: p = 0.6, e = 5 → 0.16·25 = 4(1단계 2/3 예의 "평균에서 2 벗어남"의 제곱). p = 0.95, e = 10 → 0.0025·100 = **0.25**. p = 0.999 → ≈ 0. **이 데이터**: 검증의 94%가 p < 0.1 또는 p > 0.9 → 초과 위험이 거의 0 → (d) ≈ (d-hard)(9.443 vs 9.463). 분해의 **이득은 p가 애매한 은하에서만** 나고, 그 은하는 밀도 1.5~2.0 구간의 보통 질량 은하들이다 `[추정]`.
  - [필수] **각 조각의 손실**: p는 **log loss**(cross-entropy)의 최소점이 참 확률이라(이미 배움 → 심수기 3-1 `[2단계 2/10]` MLE → cross-entropy) 보정된 확률을 준다 — 보정표가 그 확인. e는 양수 부분집합에서 **제곱 손실**이어야 E[Y|Y > 0, x] — Poisson을 쓰면 가중이 달라 (d′)가 나빠진 것(10.37).
  - [필수] **왜 기준선(한 모델)과 거의 같은가**: 기준선도 E[Y|x]를 겨냥하므로 **같은 목표**다. 분해는 목표를 바꾸지 않고 **학습을 쉽게**(0과 양수를 다른 함수로) 하는 것뿐 — 피처가 꼬리를 못 설명하는 한계는 양쪽이 같다(Top 10% 29.2 vs 29.4). 보고서 7.1에 쓸 정확한 말.
  - [선택] 두 조각이 **각각** 편향되어 있어도 곱이 맞을 수 있고 반대도 있다(곱의 편향 ≈ e·bias_p + p·bias_e). 분류기가 잘 보정되어 있으면 둘째 항만 남는다.
- **확인 문제**

(1단계 2/3 문제의 84 vs 120과 다른 것은 거기선 양수일 때 Y = 20 고정(분산 0)이었기 때문: 84 = 0 + 84, 120 = 84 + 36 — 차이 36은 같다.) 채점 포인트: 초과 위험 (c − pe)²가 분산과 무관.
  2. `(계산)` 보정표의 (0.3, 0.5] 칸: 388개, 평균 p 0.39. 이 칸의 은하들에서 e ≈ 3이라면 자르기(p ≤ 0.5 → 0)의 초과 위험 총합은 SSE에 얼마를 더하나? All RMSE²(89.1)에 비해?

#### [2단계 2/3] Poisson deviance와 RMSE의 어긋남
- **한 문장 직관**: Poisson 손실은 오차를 "평균 대비 몇 배 틀렸나"로 재므로 큰 은하의 큰 절대 오차에 RMSE만큼 화를 내지 않는다.
- **블록 목표**: (1) Poisson NLL → deviance를 쓰고 y ≥ 0 실수에서 정의됨을 안다. (2) 1차 조건으로 평균 보존을 유도한다. (3) 2차 근사로 가중 1/μ를 보이고 RMSE와의 어긋남·log 링크의 곱셈 갱신으로 (c)·(c′)의 결과를 설명한다.
- **설명할 내용**
  - [필수] **이미 배움 →** 확개응 8-1 `[1단계 1/8]`·8-2 `[1단계 1/6]` (`확률의 개념 및 응용/중간고사/`): P(Y = k) = e^{−μ}μ^k/k!, E = Var = μ. 심수기 2-1 `[2단계 2/8]` MLE, 2-2 `[2단계 2/9]` LSE = MLE("잡음 가정이 손실을 정한다"). 자분실 7 `[2단계 8/9]` 카운트 모델의 수학. **이 대회에서는**: 가우스 잡음 가정 → 제곱 손실이었듯 Poisson 가정 → 아래 손실.
  - [필수] **NLL → deviance (유도)**: −log p(y|μ) = μ − y log μ + log y!. μ에 대해 최소화하므로 log y!은 상수 → ℓ(y, μ) = μ − y log μ. **deviance** d(y, μ) := 2[ℓ(y, μ) − ℓ(y, y)] = 2[y log(y/μ) − (y − μ)] (y = 0이면 2μ). ℓ(y, y)는 "완벽 예측(μ = y)의 NLL"이라 **d ≥ 0, d = 0 ⇔ μ = y**(φ(μ) = μ − y log μ는 μ = y에서 최소 — 미분 1 − y/μ = 0). log y!이 사라졌으므로 **y는 정수가 아니어도 된다** → sklearn이 SFR에 그대로 쓴다.
  - [필수] **1차 조건 — 평균 보존**: 모델 log μᵢ = F(xᵢ)에 **절편**(상수 항)이 들어 있으면 그 절편 b에 대한 미분 Σᵢ ∂ℓ/∂b = Σᵢ(μᵢ − yᵢ)·∂log μᵢ/∂b·μᵢ/μᵢ … 정리하면 ∂ℓ/∂F = μ − y이고 절편은 모든 i에 ∂F/∂b = 1이므로 **Σᵢ(μᵢ − yᵢ) = 0** → 훈련 예측 평균 = 훈련 평균. (HGB는 F₀ = log ȳ로 시작해 이것을 대체로 유지 — 실측 예측 평균 3.68 ≈ 3.75.) 제곱 손실도 같은 성질(∂/∂F = F − y). **로그 변환 모델은 이 성질이 없다**(블록 3).
  - [필수] **2차 근사 — 가중 1/μ**: μ = y 근처에서 Taylor: d(y, μ) ≈ (y − μ)²/y ≈ **(y − μ)²/μ** (Pearson χ²). 즉 Poisson deviance는 **제곱오차를 μ로 나눈 것**과 비슷하다 — μ = 200인 은하의 오차 100은 deviance 50, μ = 2인 은하의 오차 1은 deviance 0.5. RMSE에서는 10,000 vs 1 — **1만 배**인데 deviance에서는 **100배**. 따라서 Poisson 최적화는 큰 은하의 절대 오차를 RMSE가 원하는 만큼 줄이지 않는다. 이것이 "같은 E[Y|X]를 겨냥하지만 **유한한 모델·데이터에서는** 가중이 다른 쪽을 먼저 맞춘다"의 뜻 — 모델이 완벽하면 둘이 같지만 완벽하지 않다(꼬리는 어떤 모델도 못 맞춤).
  - [필수] **log 링크의 곱셈 갱신**: 부스팅은 F = log μ를 갱신하므로 μ ← μ·exp(η·잎값). 1-2의 Newton 잎값 = Σ(y − μ)/Σμ(2차 미분 = μ). 평균 3.7에서 출발해 꼬리 200대(log 비 4.0)까지 가려면 η = 0.08로 **많은 걸음**이 필요하고, early stopping은 **deviance**(상대 오차)를 보고 멈추므로 꼬리의 절대 오차가 남아 있어도 멈춘다 → (c) 11.38. 트리 600·잎 63을 주면 9.55((c′)) — 최적화 부족이 대부분이었고, 남은 0.04는 가중 차이(구별 불가). 실습 2/3 확인 문제 2의 두 요인.
  - [필수] **그럼 Poisson은 쓸모없나**: 아니다 — (i) 예측이 **항상 양수**, (ii) 0 regime 2.0(vs 3.55), MAE 1.13(vs 1.30)으로 보통 은하를 더 잘 맞힘, (iii) 분산 ∝ 평균이 맞는 데이터라면 통계적으로 더 효율적. 지표가 RMSE인 **이 대회에서** 이기지 못할 뿐. 10절 비교표에 "트리를 충분히 주면 동등"으로 올릴 가치가 있다.
  - [선택] Tweedie(power p): 분산 ∝ μ^p, p = 1 Poisson, p = 2 Gamma(상대 오차), 1 < p < 2는 "0 덩어리 + 연속 양수"에 맞는 복합 Poisson–Gamma — sklearn "Tweedie regression on insurance claims" 예제. 완벽 ver.
- **확인 문제**
  1. `(증명·유도)` d(y, μ) = 2[y log(y/μ) − (y − μ)] ≥ 0임을 φ(μ) = μ − y log μ의 볼록성으로 보이고, y = 0일 때 d = 2μ임을 확인하라.
     - 모범 답: φ′ = 1 − y/μ, φ″ = y/μ² ≥ 0 → 볼록, 최소점 μ = y → φ(μ) ≥ φ(y) → d ≥ 0. y = 0: 0·log(0/μ)는 0으로 두고(y log y → 0) d = 2[0 − (0 − μ)] = 2μ. 즉 "0인 은하를 μ로 예측한 벌점 = 2μ"(선형!) vs 제곱 손실 μ². 채점 포인트: 볼록성 + y = 0의 벌점이 선형임.
  2. `(계산)` 두 은하: (y = 0, μ = 3)과 (y = 300, μ = 150). 각각의 제곱오차와 deviance(근사 (y−μ)²/μ와 정확한 식 둘 다)를 구하고 두 손실에서 "어느 은하를 먼저 고치려 하는지" 비교하라.
     - 모범 답: 제곱: 9 vs 22,500(**2,500배**). deviance 정확: 2·3 = 6 vs 2[300 log 2 − 150] = 2[207.9 − 150] = **115.9**(약 19배). 근사: 9/3 = 3 vs 22,500/150 = 150(50배). 두 손실 모두 큰 은하를 먼저 고치지만 **상대적 중요도가 100배쯤 다르다** → RMSE 기준으로는 Poisson이 꼬리에 덜 매달린다. 채점 포인트: 비율 비교.
  3. `(짧은 서술)` 보고서 7.1에 "Poisson 손실은 0을 자연스럽게 다루고 양수 예측을 보장하지만 공식 지표에서 기준선에 졌다"를 쓸 때, 심사자가 "왜?"라고 물으면 두 문장으로 답할 것은?
     - 모범 답 요지: (1) deviance는 오차를 평균 대비 상대적으로(≈ (y−μ)²/μ) 재므로 RMSE가 지배받는 꼬리의 절대 오차를 덜 벌한다. (2) log 링크의 곱셈 갱신은 꼬리까지 가는 데 트리가 많이 필요한데 deviance 기준 early stopping이 먼저 멈췄다 — 트리 600개를 주면 동등(9.55). 채점 포인트: 가중 + 최적화.
- **막히면**: 제곱 손실의 "자"는 눈금이 같은 자, deviance는 **눈금이 μ에 비례해 늘어나는 자** — 큰 은하에서는 눈금이 커서 같은 절대 오차가 작게 읽힌다.
- **다음 블록 연결**: 마지막으로 로그 변환 모델이 왜 체계적으로 작은지 — Jensen.

#### [2단계 3/3] Jensen과 되돌림 보정
- **한 문장 직관**: 로그의 평균을 되돌리면 평균이 아니라 그보다 작은 값이 나오고, 그 차이는 로그 척도의 흩어짐이 클수록 크다.
- **블록 목표**: (1) Jensen으로 되돌림 편향의 **방향**을 증명한다. (2) 로그정규 가정의 보정 e^{σ²/2}와 Duan smearing을 유도·연결하고 실측(1.0297 vs 1.0326)을 읽는다. (3) 상수 보정이 안 되는 경우(이분산)를 말한다.
- **설명할 내용**
  - [필수] **이미 배움 →** 심수기 2-1 `[2단계 7/8]` KL ≥ 0과 상호정보량 증명 (`심층신경망의 수학적 기초/중간고사/2-1_수업정리.md`): **Jensen 부등식** — φ 볼록이면 E[φ(Z)] ≥ φ(E[Z]), 등호 ⇔ Z 상수. **이 대회에서는**: φ = exp(볼록, φ″ = e^z > 0), Z = log(1 + Y)|x.
  - [필수] **편향의 방향 (증명)**: 로그 모델은 g(x) ≈ E[Z|x] = E[log(1+Y)|x]를 맞힌다. 되돌린 예측 exp(g(x)) − 1 ≈ exp(E[Z|x]) − 1 **≤** E[exp(Z)|x] − 1 = E[1 + Y|x] − 1 = **E[Y|x]** (Jensen). 등호는 x를 고정했을 때 Y가 상수일 때만 → 조건부 분산이 있는 한 **항상 과소예측**. 실측: 예측 평균 3.347 < 3.751(−10.8%). 지표가 E[Y|x]를 요구하므로 이 편향이 그대로 RMSE 손해(All 9.81 vs 9.51, Top 10% 30.9).
  - [필수] **얼마나 작은가 — 로그정규 (유도)**: Z|x ~ N(m, σ²)이면 E[e^Z|x] = e^{m + σ²/2} (적분: ∫e^z·(2πσ²)^{−1/2}e^{−(z−m)²/2σ²}dz, 지수를 완전제곱으로 — z의 계수를 모으면 −(z − (m + σ²))²/2σ² + m + σ²/2) `[보충: 확개응 Lecture 6(확률변수 함수의 분포)이 10-28에 다룰 내용 — 거기서 배우면 그 경로로 대체]`. 따라서 **보정 = e^{σ²/2}**를 곱한다. 또 exp(m) = **중앙값**(로그정규의 중앙값은 e^m) → "로그 모델은 조건부 중앙값을 내놓는다"(1단계 1/3). 실측: 훈련 로그 잔차 분산 0.0585 → e^{0.029} = **1.0297**.
  - [필수] **Duan smearing (유도)**: 정규 가정 없이 E[e^ε]을 **잔차의 표본 평균**으로 추정: ŝ = (1/n)Σᵢ e^{ε̂ᵢ}, ε̂ᵢ = zᵢ − ĝ(xᵢ) (훈련 데이터). 되돌림: ŷ = e^{ĝ(x)}·ŝ − 1. 근거: Y + 1 = e^{g(x)}·e^ε이고 ε이 x와 독립(등분산)이면 E[Y + 1|x] = e^{g(x)}·E[e^ε]. 실측 ŝ = **1.0326** — 정규 보정 1.0297과 거의 같다(로그 잔차가 거의 정규라는 뜻).
  - [필수] **왜 보정해도 3.49 < 3.75인가**: 두 유도 모두 **ε이 x와 독립(등분산)**을 가정했다. 꼬리 은하에서 로그 잔차의 분산이 더 크면(σ²(x) 증가) 거기엔 더 큰 보정이 필요한데 상수 ŝ는 전체 평균이라 작다 → 꼬리는 여전히 과소. 이분산 보정(x별 σ²(x) 추정, 또는 **제곱 손실로 직접 E[Y|x]를 맞히는 (a)**)이 대안 — 이 대회에선 (a)가 그냥 그 일을 한다. 또 1 + y의 로그는 작은 y를 늘리고 큰 y를 **압축**해 트리의 해상도를 꼬리에서 떨어뜨린다 `[추정]`.
  - [선택] 로그 모델의 장점은 **0 regime과 MAE**(실측 0.96, 1.09로 최선) — 중앙값 쪽 예측은 이상치에 끌리지 않는다(자분실 7 L1). 지표가 MAE였으면 (b)가 이긴다.
- **확인 문제**
  1. `(증명·유도)` Z ~ N(m, σ²)일 때 E[e^Z] = e^{m + σ²/2}를 완전제곱으로 유도하라. m = 1.5, σ² = 0.0585이면 exp(E[Z])와 E[exp(Z)]는 각각 얼마이고 비율은?
     - 모범 답: 지수 z − (z−m)²/(2σ²) = −[z² − 2(m + σ²)z + m²]/(2σ²) = −(z − (m+σ²))²/(2σ²) + (m + σ²/2) → 적분하면 e^{m+σ²/2}. e^{1.5} = 4.48, e^{1.529} = 4.61, 비율 **1.0297**. 채점 포인트: 완전제곱, 비율이 σ²에만 의존.
  2. `(계산)` 어떤 x에서 Y가 {0, 1, 2, 10}을 각 1/4 확률로 갖는다. (a) E[Y|x] (b) E[log(1+Y)|x]를 되돌린 값 (c) Jensen이 말하는 부등호 방향이 맞는지 (d) 이 네 값이 로그정규가 아닌데도 smearing 식 E[e^Z]/e^{E[Z]}은 얼마인가?
     - 모범 답: (a) 13/4 = **3.25**. (b) E[Z] = (0 + 0.693 + 1.099 + 2.398)/4 = 1.0475 → e^{1.0475} − 1 = **1.85** < 3.25 ✓. (d) E[e^Z] = E[1 + Y] = 4.25, e^{E[Z]} = 2.85 → 비율 **1.49**(로그정규 공식 e^{σ²/2}은 여기 Var(Z) ≈ 0.76 → 1.46으로 비슷). 채점 포인트: 되돌린 값이 평균보다 훨씬 작음, 분산이 크면 보정도 크다.
  3. `(검토)` 팀원이 (b′)를 "smearing으로 편향을 제거했다"고 7.1에 썼다. 실측(3.49 vs 3.75)으로 고쳐 쓸 문장은?
     - 모범 답 요지: "smearing(1.033)이 편향을 **일부**(3.35 → 3.49) 줄였지만 등분산 가정이 꼬리에서 깨져 평균이 여전히 7% 작다; RMSE는 9.81 → 9.79로 변화 없음(구간 안)". 채점 포인트: "제거" → "일부", 숫자.
- **막히면**: Y ∈ {1, 100} 반반인 예: 평균 50.5, log의 평균은 (0 + 4.6)/2 = 2.3 → e^{2.3} = 10. "로그로 평균을 내면 큰 값이 눌려서 10이 나오고, 되돌려도 10이다 — 50.5가 아니다."

### 4.4 2단계 완료 체크리스트
- [ ] E[Y|x] = p·e를 총기대 법칙으로 유도하고, 조건부 위험 = Var + (c − pe)²에서 자르기의 초과 위험을 계산한다.
- [ ] 분해의 이득이 p가 애매한 은하(6%)에서만 나는 이유를 식으로 말한다.
- [ ] Poisson NLL → deviance(≥ 0, 실수 y)를 쓰고 1차 조건(평균 보존)·2차 근사(1/μ 가중)를 유도한다.
- [ ] (c) 11.38 → (c′) 9.55를 "최적화 부족 + 가중 차이"로 설명한다.
- [ ] Jensen으로 되돌림 편향 방향을 증명하고 e^{σ²/2}·smearing을 연결하며 실측(1.0297 / 1.0326, 3.49 < 3.75)을 읽는다.
