## 2026년 11월 7일 위치·속도에서 환경을 읽는 EDA

[환경 EDA](2026-11-07_위치속도_환경EDA.md)에서 천문학의 표준 환경 정의(이웃 밀도, FoF 그룹의 중심/위성, 호스트 질량, 은하단 중심 거리 r/R200, 위상공간 속도)를 `pos_*`, `vel_*`에 적용했다. 중심 은하는 어떤 질량에서도 0.4~0.7%만 SFR=0이고 위성만 퀜칭되며, 호스트 질량 10^13.5 근처에서 위성의 0 비율이 4%에서 39%로 뛴다. 제공 밀도는 약 2 h⁻¹ Mpc 이웃 수와 같고(Spearman 0.955), 어제의 낮은 밀도 0 은하 435개는 94%가 FoF 위성이다. K-means는 환경을 못 찾는다(AUC 0.62 대 FoF 0.96). 환경 피처를 더하면 중간 구간 0 분류 정확도가 5-fold에서 90.98% → 93.34%로 오르고 양수 회귀는 변화가 없다. 피처 정의표를 구현용으로 정리했다.

## 2026년 11월 7일 정규분포 관찰의 이론 검토

[이론 검토](2026-11-07_정규분포_이론검토.md)에서 어제의 "중간 구간 정규분포" 관찰을 시뮬레이션·밀도장·퀜칭 이론으로 설명하고 학습 분할에서 확인했다. 종 모양은 정규분포에서 뽑은 것이 아니라 **오른쪽으로 치우친 전체 밀도 분포 × 밀도의 시그모이드 퀜칭 비율**의 곱이다. SFR=0은 별 생성 가스가 없는 이산 상태이고(최소 양수 SFR 0.0073 ≈ 문턱 밀도 가스 입자 하나의 SFR 0.0071, Oku & Nagamine 2024 처방으로 계산), 질량(블랙홀) 퀜칭은 0이 아니라 낮은 sSFR로 나타난다. Peng 외 2010의 분리 가설은 기각됐고, 같은 밀도에서는 가벼운 은하가 더 자주 0이다. 제출용 모델은 바꾸지 않았다.

### 월요일 보고용 요약
- **검증**: 고르기는 train 안 5-fold CV, 보고는 공통 분할 val에서 한다. fold RMSE가 5.4~14.4로 흔들린다. 어느 fold에 SFR 2145·1414 같은 극단 은하가 들어갔는지가 RMSE를 정하기 때문이다. 그래서 설정 간 차이(≤ 0.2)를 가를 수 없고, 하이퍼파라미터는 기준선 값으로 고정했다.
- **기준선**: val RMSE 9.513(중앙값 기준선 12.345). 실제로 쓴 트리는 150개가 아니라 37개다(early stopping). SFR > 100인 61개(0.15%)가 SSE의 85.5%이고 평균 −147로 과소예측한다. 0 은하는 평균 +1.21로 과대예측하고, 음수 예측이 19개 있다.
- **예비 모델 = 2단계 P(SFR>0|x) × E[SFR|SFR>0,x]**: All RMSE 9.434는 기준선과 **동등**하다(차이 −0.08, 95% 구간 [−0.35, +0.18]). SFR = 0 RMSE는 3.55 → 2.91로 줄었고 음수 예측은 0개다. log1p는 MAE·0 regime은 가장 좋지만 RMSE에서 진다(Jensen 되돌림 편향). Poisson은 같은 설정에서 확실히 나쁘고(11.38), 트리를 늘리면 동등하다.
- **팀원 EDA와 연결**: 분류기는 주변 밀도에 압도적으로 기댄다(EDA 1·2). 양수 회귀기는 항성 질량·전구체 질량·BH를 쓰고 밀도는 쓰지 않는다. BH를 빼면 확실히 나빠진다(+0.45 [+0.19, +0.75], EDA 4가 제안한 비교). 위치·속도 6열은 빼도 동등하다.
- **8절(다음 계획) 후보**: 꼬리(SFR > 100) 다루기, 분류기 트리 수(상한 150에 닿음), 위치·속도 대신 만든 피처(이웃 밀도 등)나 제외 여부, 피처 선택 확정(4절, 팀원과 상의).
