### 월요일 보고용 요약
- **검증**: 고르기는 train 안 5-fold CV, 보고는 공통 분할 val에서 한다. fold RMSE가 5.4~14.4로 흔들린다. 어느 fold에 SFR 2145·1414 같은 극단 은하가 들어갔는지가 RMSE를 정하기 때문이다. 그래서 설정 간 차이(≤ 0.2)를 가를 수 없고, 하이퍼파라미터는 기준선 값으로 고정했다.
- **기준선**: val RMSE 9.513(중앙값 기준선 12.345). 실제로 쓴 트리는 150개가 아니라 37개다(early stopping). SFR > 100인 61개(0.15%)가 SSE의 85.5%이고 평균 −147로 과소예측한다. 0 은하는 평균 +1.21로 과대예측하고, 음수 예측이 19개 있다.
- **예비 모델 = 2단계 P(SFR>0|x) × E[SFR|SFR>0,x]**: All RMSE 9.434는 기준선과 **동등**하다(차이 −0.08, 95% 구간 [−0.35, +0.18]). SFR = 0 RMSE는 3.55 → 2.91로 줄었고 음수 예측은 0개다. log1p는 MAE·0 regime은 가장 좋지만 RMSE에서 진다(Jensen 되돌림 편향). Poisson은 같은 설정에서 확실히 나쁘고(11.38), 트리를 늘리면 동등하다.
- **팀원 EDA와 연결**: 분류기는 주변 밀도에 압도적으로 기댄다(EDA 1·2). 양수 회귀기는 항성 질량·전구체 질량·BH를 쓰고 밀도는 쓰지 않는다. BH를 빼면 확실히 나빠진다(+0.45 [+0.19, +0.75], EDA 4가 제안한 비교). 위치·속도 6열은 빼도 동등하다.
- **8절(다음 계획) 후보**: 꼬리(SFR > 100) 다루기, 분류기 트리 수(상한 150에 닿음), 위치·속도 대신 만든 피처(이웃 밀도 등)나 제외 여부, 피처 선택 확정(4절, 팀원과 상의).
