# 계층형 46피처 모델의 분류 확률 보정

기준은 기존 무가중치 LightGBM과 극단값 가중치3배 LightGBM을 50:50으로 섞은 모델이다. 그 회귀 예측을 고정한 채 두 HGB 분류기의 확률을 보정했다. 현재 채택 모델이나 GitHub는 변경하지 않았다.

## 세 시드에서 확인된 후보

- 전체·SFR>100 RMSE가 함께 개선된 방법: **없음**.
- 전체 증가를 상대0.1% 이내로 제한하면서 SFR>100이 개선된 방법: **없음**.
- 위 조건에 실제0 RMSE 증가 없음까지 만족한 방법: **없음**.

별도로, 전체 증가0.1% 이내에서 실제0 RMSE가 세 시드 모두 증가하지 않은 방법은 **sigmoid — 0/양수만, sigmoid — 두 분류기 모두, isotonic — 두 분류기 모두**이다. 이들은0 구간을 위한 절충 후보이며, 꼬리 오차까지 개선한 것으로 해석하지 않는다.

이는 미리 정한 여섯 방법을 반복 검증에서 관측한 결과다. 보정 방법을 바깥 검증 정답에 맞춰 학습하지 않았으며, 모든 방법을 보고·저장했다. 위 목록이나 결과 순위는 탐색적 평가이며 독립 테스트에서의 우위를 보장하지 않는다.

## 실험 조건

- 0/양수 확률만 보정, 양수 내 중간/꼬리 확률만 보정, 둘 다 보정하는 세 경우를 sigmoid와 isotonic 각각에서 시험했다.
- 46피처, 두 HGB400 분류기의 설정, 일반 HGB 회귀기, 50:50 꼬리 회귀기, 학습 경계SFR>10, 극단값 평가SFR>100을 유지했다.
- P(SFR=0)≥0.9이면0으로 예측하는 규칙은 유지했다. 보정 때문에 그 조건을 만족하는 행은 달라질 수 있다.
- 평가 지표는 log10(1+SFR)의 무가중치 RMSE다. 전체는5개 fold 평균, 실제0과 극단값은 합친 OOF 점수다.
- 원래 train80%의 동일한 세 시드42·7·99로5-fold를 평가했다. 원래 holdout20% 정답은 이번 실험에서 사용하지 않았다.
- 평가 행166,749개 중 SFR>100은209개다.

## 보정 데이터 누수 방지

각 바깥 학습 fold를 다시3-fold로 나눴다. 내부 학습 행으로 피처 잔차 계산기와 두 분류기를 학습하고, 내부 검증 행의 확률을 모아 보정기를 학습했다. 0/양수 보정에는 모든 행, 중간/꼬리 보정에는 **실제 양수 행만** 사용했다. 바깥 검증 행은 보정기 학습에 들어가지 않았다.

보정기는 내부 교차검증 확률로 학습한 뒤 바깥 학습 전체로 학습된 분류기에 적용했다. 내부 모델과 전체 모델은 학습 표본 수가 다르므로 확률 분포 차이가 생길 수 있으며, 바깥 검증 점수는 이 적용 방식까지 포함한 결과다. 예측 시에는 정답 구간을 사용하지 않는다.

sigmoid는 확률의 logit을 입력으로 하는 LogisticRegression(C=1e6)이다. isotonic은 증가 방향의 비모수 보정이다. 세 시드 모두 같은 관측치를 재분할했으므로 새 독립 테스트가 아니다.
