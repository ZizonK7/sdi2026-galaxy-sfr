# A-log 부품 교체 실험 결과

기존의 3분류 → 일반/꼬리 회귀 → 로그 공간 확률 혼합 구조를 유지하고, 6가지 부품 교체를 실제로 비교했다.
최저 OOF 로그 RMSE는 **⑥ 꼬리 회귀 → ExtraTrees: 0.107314**이다.

## 비교 기준

- 데이터: main `fef00ffaf2992104c8d6dc0e87ab0b30275d8c9d`의 CSV와 Git blob SHA 일치 확인.
- 기존과 같은 80% 학습 표본 166,749개, 같은 5-fold와 행 순서를 사용했다. 남겨둔 20% holdout은 평가하지 않았다.
- 클래스는 실제 SFR로 정의했다: 0 / 0<SFR≤10 / SFR>10. 회귀기는 각 실제 부류에 해당하는 학습 표본으로만 학습했다.
- 모든 후보는 원래의 13개 입력, T=10, log_offset=1을 유지한다. 회귀 목표는 ln(1+SFR), 최종 평가는 log10(1+SFR)의 RMSE이다.
- 예측은 `expm1(p_normal * max(z_normal,0) + p_tail * max(z_tail,0))`. 0 부류의 로그 예측은 0이다.
- 이 비교는 기존 실험의 log10(1+SFR) 정의에 고정한 결과다. 공식 평가식의 0 처리 방식이 다르면 그 정의로 재평가해야 한다.
- 후보마다 미리 정한 설정 하나를 사용했다. 모델별 용량과 시간이 달라 알고리즘 자체의 절대 우열을 입증하는 실험은 아니다.

## 결과 해석과 다음 판단

이번 설정에서는 **HGB 분류 + HGB 일반 회귀 + ExtraTrees 꼬리 회귀**가 가장 좋은 후보였다.
기존 대비 개선은 0.000133, 약 0.12%로 작지만 5개 fold 중 4개에서 개선됐다.
따라서 기존 A를 기준으로 유지하면서 ExtraTrees 꼬리 회귀를 다음 검증 후보로 남기는 것이 적절하다.
검증 fold들이 학습 데이터를 공유하므로 4/5 승리를 독립 반복 실험이나 통계적 유의성으로 해석하지 않는다.

- 분류기: CatBoost와 스플라인 모두 최종 로그 RMSE가 악화됐다. gate log loss도 HGB 0.095127, CatBoost 0.105926, 스플라인 0.110981 순이었다. 이번 조건에서는 HGB 분류기를 유지한다.
- 일반 회귀: 두 대안 모두 전체 점수가 악화됐다. 스플라인은 일부 구간에서 개선됐지만 표본이 많은 0<SFR≤3 구간에서 손해가 났다. HGB를 유지한다.
- 꼬리 회귀: ExtraTrees는 10<SFR≤30에서 0.144795→0.142111, 30<SFR≤100에서 0.218490→0.214752로 개선됐지만, SFR>100에서는 0.672682→0.690616으로 악화됐다. 전체 개선을 극단 꼬리 개선으로 해석하면 안 된다.
- 실제 꼬리 표본만 놓고 본 회귀기 진단에서는 CatBoost도 HGB보다 좋았다. 그런데 최종 혼합 점수는 나빠졌다. 전문가 자체의 오차만으로 채택하지 않고 전체 혼합 예측을 검증해야 함을 보여준다.
- 조장의 밀도·질량 관련 단서는 후보 설계에 활용했지만, 해당 스플라인 형태가 이 구조의 성능 향상으로 이어진다는 근거는 이번에 얻지 못했다.

다음 실험은 분류와 일반 회귀를 HGB로 고정하고 ExtraTrees의 잎당 최소 표본 수를 소규모로 비교하는 것이 우선이다.
튜닝은 내부 검증에서 수행하고, 선택된 설정은 별도의 사전 고정 검증에서 확인해야 한다.
CatBoost는 이번 한 설정만으로 배제할 수 없으나, 추가 탐색은 현재 소폭 개선을 보인 꼬리 회귀보다 후순위다.

## 조장의 발견을 반영한 방식

조장의 기존 분석은 밀도가 0 분류에, 별·전구체·블랙홀 질량이 양의 SFR 회귀에 유용하다는 단서를 주었다.
다만 기존 모델과 평가 지표에서 얻은 관찰이므로 이번 A-log에서 검증할 가설로 취급했다.

- 스플라인 분류기: 앞의 7개 물리량에 5개 균등 knot의 3차 스플라인, 밀도×별 질량의 스플라인 상호작용. 위치·속도 6개는 선형 입력으로 유지. 표준화 후 다항 로지스틱 회귀(C=1, 최대 1500회).
- 스플라인 일반 회귀기: 동일한 기본 변환에 별 질량×BH 질량, 별 질량×전구체 별 질량 상호작용. 표준화 후 Ridge(alpha=10).
- 변환은 각 fold의 해당 부품 학습 표본에서만 학습했다. 양 끝 바깥에서는 스플라인을 상수로 연장했다. 중복값이 많은 질량 변수 때문에 분위수 knot 대신 균등 knot를 사용했다.
- CatBoost: 300회, depth=6, learning_rate=0.05, l2_leaf_reg=5. 분류 MultiClass, 회귀 RMSE. 검증 fold를 조기 종료에 사용하지 않았다.
- ExtraTrees 꼬리 회귀: 300개 나무, min_samples_leaf=5, max_features=1.0, squared_error.
- HGB 기준: learning_rate=0.08, max_iter=150, max_leaf_nodes=31, random_state=42. 기존 조기 종료 기본값 유지.
- 밀도 가우시안 값을 정답 확률로 고정하거나 예측값에 곱하지 않았다. 밀도 구간을 A의 세 목표 부류와 동일시하지 않았다.

선택된 조합(분류 / 일반 / 꼬리): `hgb_gate / hgb_mid / extra_tail`.

## 검증과 재현

- 3개 단위 테스트 통과: 로그 혼합식, 검증 입력에 의한 스플라인 재학습 방지, 재사용 추정기의 clone/예측 일치.
- 기존 A의 OOF 예측과 허용 오차 1e-9 안에서 재현 확인. 모든 예측의 유한성·비음수 확인.
- 저장한 OOF 예측에서 전체 및 fold 점수를 별도로 재계산해 일치 확인.
- 학습 경고 발생 부품/fold: 0개. 자세한 내역은 `fit_details.json`.
- 전체 실험 시간: 313.2초. 부품별 시간은 `fit_times.csv`.

```bash
python -m pip install -r requirements.txt
python test_components.py
python run_experiment.py --data '/path/to/Galaxy Features with Position and Velocity for Star Formation Rate Prediction.csv' --references baseline_reference.npz --out rerun
```

`component_models.py`의 `ComponentLogMixture(gate=..., mid=..., tail=...)`로 선택한 구조를 다시 학습할 수 있다.
이 실행은 모델 비교용 OOF 예측을 저장했다. 전체 학습 데이터로 재학습한 배포 모델은 포함하지 않는다.
