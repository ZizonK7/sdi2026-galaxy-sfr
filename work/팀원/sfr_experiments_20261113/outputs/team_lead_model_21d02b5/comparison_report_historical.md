# HGB·LightGBM·CatBoost 비교 결과 (2026-11-12)

**최종 선택은 LightGBM 두 단계 모델입니다.** HGB 400회 두 단계의 교차검증 평균 로그 RMSE는 0.095340, LightGBM은 0.095367로 관측 차이가 0.000027 dex였다. 평균 학습 시간은 각각 13.44초와 6.76초로, 관측 정확도의 작은 차이를 수용하고 학습 시간이 약 49.7% 짧은 LightGBM 두 단계를 최종 모델로 선택했다. 기존 조기 종료 HGB의 시간은 6.75초였으므로, 시간 이점의 비교 대상은 HGB 400회 후보입니다. 최종 노트북의 모델 코드·검증 점수·오차 분석·모델 카드도 LightGBM으로 갱신했습니다.

## 비교 조건

- 제공 CSV 208,437행 중 기존 80:20 층화 분할의 학습 166,749행만 후보 평가에 사용했습니다. 외부 검증 41,688행의 타깃은 학습·후보 채점에 쓰지 않았습니다. 전체 타깃의 0 여부는 공통 층화 분할에만 사용했습니다.
- 동일한 34개 피처(원래 13 + 환경 17 + 성장·비율 4), 동일한 KFold(5, shuffle=True, seed=42)를 사용했습니다. 환경 피처는 FAQ에 따라 전체 은하의 입력 기하로 만들고, 최종 노트북과 같은 사전식 정렬을 적용했습니다.
- 학습·평가 로그 정의는 **log10(SFR + 1)**입니다. +1은 기존 팀 가정을 유지한 값이며, 공식 offset이 다르면 이 순위를 그대로 적용할 수 없습니다. 음수 역변환 예측은 SFR=0으로 절단한 뒤 평가했습니다.
- 통제 비교 6개는 학습률 0.08, 400회 학습, 조기 종료 없이 설정 하나씩을 실행했습니다. 기존 제출 모델은 원래의 조기 종료를 유지해 별도로 재현했습니다. 모든 두 단계 모델의 0 판정 문턱은 0.9로 고정했습니다.
- HGB·LightGBM은 최대 잎 31개, CatBoost는 대칭 트리 깊이 5(최대 잎 32개)입니다. 세부 기본값과 실제 계산량까지 같은 비교는 아닙니다. CPU 6개 스레드로 순차 실행했습니다.
- 결과를 보기 전에 protocol.json에 순위와 탐색 후보 규칙을 고정했습니다. 기존 제출 모델보다 평균 RMSE가 낮고 4/5개 이상 분할에서 낮을 때만 추가 검토 후보로 표시했습니다.

## 해석과 보고서에 옮길 문장

동일한 34개 입력과 학습 내부 5-fold에서 HGB, LightGBM, CatBoost의 단일 로그 회귀 및 두 단계 구조를 비교했다. 이번 설정에서 가장 낮은 평균 로그 RMSE는 HGB 두 단계 · 400회의 0.095340였으며, 기존 제출 모델(0.096619) 대비 1.32% 낮았다. 통제 비교에는 각 알고리즘·구조 조합의 고정 설정 하나만 사용했으므로 탐색적 비교로 해석한다. 비교 결과 확인 후 관측 정확도 차이와 학습 시간을 절충해 LightGBM을 선택했다. 정확도 동등성을 입증한 것은 아니다.

HGB와 LightGBM 두 단계의 평균 차이는 약 0.000027 dex로 작습니다. 이번 기록의 순위만으로 두 알고리즘의 일반적인 우열을 판단할 수 없습니다. 두 단계 구조는 세 알고리즘 모두에서 단일 회귀보다 5/5개 분할의 오차가 낮았습니다.

보고서 9절에는 비교 동기와 고정 설정을, 10절에는 위 결과표와 분할별 차이를 넣을 수 있습니다. 이 수치를 기존 보고서의 외부 검증 점수와 같은 종류의 결과로 섞지 않아야 합니다.
