# 조교 FAQ 답변 원문 (2026-11-11 저장)

조교에게서 받은 질의응답 원문이다. 아래 영어 본문은 받은 그대로이며 고치지 않았다.

---

Q1. Can the position and velocity information be used for feature engineering?
A. Yes. Students may construct physically motivated environmental features from the provided position and velocity information. Periodic boundary conditions should be taken into account when calculating spatial separations.

Q2. Can features from validation/test galaxies be used when constructing environmental features?
A. Yes, as long as no target information (sfr_linear) is used and the same procedure can be applied to an unlabeled evaluation dataset.

Q3. Can separate models be used for different SFR regimes?
A. Yes. However, for validation/test galaxies, the regime should be inferred from the input features rather than the true SFR, for example using a classifier.

Q4. How should galaxies with SFR = 0 be treated?
A. SFR = 0 is a valid target value and should not be treated as missing data or removed from the analysis.

Q5. Can gravitational or neighborhood-based quantities be used as features?
A. Yes. Physically motivated gravitational or neighborhood-based feature engineering is allowed.

Q6. What are the evaluation criteria for the final submission?
A. The primary quantitative criterion will be the RMSE in log-SFR space. We will first use predictive performance on the evaluation dataset to select a subset of teams. In the subsequent evaluation, greater emphasis will be placed on the report, including the intermediate steps of the analysis, the reasoning behind modeling choices, and the interpretation of the results. Therefore, the final evaluation will consider not only predictive accuracy but also the quality of the scientific reasoning and analysis presented in the report.
